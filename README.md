# @enormora/identity-esm

No operation exported as ECMAscript module.

## Install

```sh
npm install @enormora/identity-esm
```

## Usage

```typescript
import { identity } from '@enormora/identity-esm';

const result = identity('foo'); // 'foo'
```

## Releases

The release workflow prepares a changelog pull request with Packtory. CI validates its contents; publishing runs only after an authorized release pull request merges. Dependency updates are grouped in the changelog.
